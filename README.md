# 你好，我是 DrizzleGig（细雨歌）👋

DSH（[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)）插件作者，正在做 **DSH-novel** 系列：一套给长篇小说用的 AI 写作工具。

「AI 能不能写」，并且它能不能在几十万字里记住该记住的、尊重已经定下的设定、写出作者想要的风格，并在关键处让作者拍板。**AI 可以承担更多工作，但故事的方向、取舍与最终判断，应该始终掌握在作者手中。**

> Hi, I'm DrizzleGig, a DSH (DeepSeek Harness) plugin author building **DSH-novel** — a set of tools for long-form fiction with AI. About whether AI can write and more about whether it can stay coherent across a very long story, respect what's already established, write in the voice the author wants, and let the author make the calls that matter. AI can do more of the work; the story should still belong to the person who imagines it.

## 现在 / 下一步

beat / fade / fanfic / voice 四个已经发布，分别解决剧情决策、长篇记忆、同人设定与写作风格。下一步开发 `conductor`——让各个插件协同工作。由 conductor 连接各项能力，构建完整的 AI 长篇小说创作生态，整合 `dsh-novel-Pro`。
